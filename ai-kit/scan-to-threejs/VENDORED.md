# Vendored from wesbos/3d-model-anything

These files are an unmodified copy of the `scan-to-threejs` agent skill from
https://github.com/wesbos/3d-model-anything (`.agents/skills/scan-to-threejs/`, commit
`31b2dc9da3fb541e501f2f0936e55b32afb70ee8`). They are MIT licensed; see `LICENSE`.

Included: `SKILL.md`, `references/*.md`, and the scripts that work on a bundle by
themselves (`bundle_to_room.py`, `bundle_plan.py`, `prepare_photos.py`,
`reconstruct_bundle.py`, `photos_for.py`). The matched-camera capture helpers (`cap.sh`,
`cmp.sh`, `cmp_photo.sh`) and the three.js room viewer they drive live in the full
repository. Clone it if you want that exact comparison loop.
